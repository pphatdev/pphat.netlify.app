# ✨ **About Project**

pphat-netlify-app is a comprehensive personal portfolio and blog website by PPhat (Leat Sophat), a Senior Frontend Developer.
This modern web application showcases his professional journey, technical expertise, and creative projects.
The site features a dynamic blog with MDX support, an interactive gallery, integrated contact functionality, and complete SEO optimization with RSS/Atom feeds.
Built with the latest Next.js 15 and React 19, it demonstrates best practices in modern web development with server-side rendering, static site generation, and progressive enhancement.

# 🛠️ **Project Tech Stack**

- **Core:**
  - Next.js `v15.5.12`
  - React `v19.2.1`
  - TypeScript `v5`

- **UI & Styling:**
  - TailwindCSS `v4.1.1`
  - Radix UI Components
  - Shadcn/ui
  - Framer Motion `v11.18.2`
  - Lucide React Icons
  - TailwindCSS Typography

- **Content & Editor:**
  - TipTap `v2.12.0` (Rich Text Editor)
  - React Markdown `v10.1.0`
  - Gray Matter (Frontmatter)
  - Rehype & Remark Plugins
  - Highlight.js

- **Features & Utilities:**
  - Next Themes `v0.4.6` (Dark Mode)
  - Embla Carousel `v8.5.2`
  - Recharts `v2.15.2` (Charts)
  - Nodemailer (Email)
  - Sonner `v2.0.3` (Toast Notifications)
  - Next SEO
  - Next Progress Bar
  - Date-fns

- **Development:**
  - ESLint
  - Turbo
  - PostCSS
  - Autoprefixer
