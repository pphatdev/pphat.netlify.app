# ✨ **About Project**

pphat.vercel.app is a modern personal portfolio website by PPhat (Leat Sophat), a Senior Frontend Developer.
This sleek and responsive web application showcases his professional journey, technical expertise, and creative projects.
The site features an elegant design with dark/light theme support, interactive animations, and seamless user experience.
Built with Next.js 15 and React 19, it demonstrates cutting-edge web development practices with optimized performance and modern UI components.

# 🛠️ **Project Tech Stack**

- **Core:**
  - Next.js `v15.5.10`
  - React `v19.0.0`
  - TypeScript `v5`

- **UI & Styling:**
  - TailwindCSS `v4`
  - Radix UI Components
  - Framer Motion `v12.18.1`
  - Lucide React Icons `v0.515.0`
  - Class Variance Authority
  - Tailwind Merge

- **Features & Utilities:**
  - Next Themes `v0.4.6` (Dark Mode)
  - Canvas Confetti `v1.9.3`
  - Axios `v1.13.5`
  - Nodemailer `v7.0.11` (Email)
  - Schema-DTS (Structured Data)
  - Vaul `v1.1.2` (Drawer)

- **Development:**
  - ESLint
  - PostCSS
  - Dotenv

# 🌈 **Project Features**

- About Me Section
- Tech Stack Showcase
- Work Experience Timeline
- Featured Projects
- Contact Form
- Dark/Light Theme Toggle
- Smooth Animations
- Responsive Design
- SEO Optimized
- Interactive UI Components
